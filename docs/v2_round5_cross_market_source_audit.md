# Round 5 cross-market source audit

This audit implements the registered data round. It does not select a neural experiment. All historical observations end at 2024-12-30; raw and previously canonical archives remain immutable. Source metadata and documentation can describe later website migrations or ticker changes without admitting later market outcomes.

The acquisition and normalization command is `uv run --project research python -m brazil_rv.v2.round5_cross_market`. New artifacts reside beneath `D:\quant-data\b3\interim\round5_data_20260910T140442Z\cross_market`. The final manifest records source URLs, response hashes, coverage, parsing failures, timing rules and output hashes. `di_dce_us_subset` is an interim join-development artifact; the final root supersedes that subset for research consumers.

The final manifest SHA-256 is `0fde6503ad65e9d99ebfa50fdb50db63a0a300768ba76996ef0b93fa78825864`. All transient network failures were recovered. Of 3,130 dated SHFE requests/reused files, 2,921 were retrieved and 209 returned HTTP 404. The archive contains 22,293 DI tenor observations, 99,691 futures contract observations, 8,486 calendar-checked futures returns and 69,029 US return rows. Untimed SUZ rows remain in the latter archive and must be filtered by the consumer.

**DI source and units.** The six-tenor SGS route in the supplied document was not established. The official B3 dated archive works back to 2010: [example 2010 file](https://www.b3.com.br/pesquisapregao/download?filelist=TS100104.ex_,), [official fixed-width layout](https://www.b3.com.br/data/files/E6/B6/70/64/BB1379106B8BCB69AC094EA8/TaxaSwap%20para%20UP2DATA.xlsx), [B3 curve methodology](https://www.b3.com.br/data/files/47/77/2A/76/99BCB710D30FE9B7AC094EA8/Manual%20de%20Curvas.pdf). The PRE curve derives from DI1 settlements, with 252-business-day annual compounding. The parser uses the nominal fixed vertex code, preserving actual rolled calendar and working days separately. Selecting by actual maturity would incorrectly lose quotes such as the nominal 90-day vertex whose holiday-adjusted maturity is 91 days.

The 3,911 weekday requests produced 3,716 valid curve dates, 193 empty archives and two stale holiday responses (2010-12-24 returned 2010-12-23; 2010-12-31 returned 2010-12-30). Those two responses are audited and excluded. The 90-day fixed vertex is absent on 2012-04-24 and 2014-12-23; the 360-day vertex is absent on 2014-12-23. The other published vertices remain observed. No curve interpolation or invented rate is used. `available_at` uses an explicitly documented after-close bound with the same first B3 decision as the true settlement publication; it does not claim a measured historical publication timestamp.

**Asian contract continuity and missing sessions.** Futures shocks are direct log settlement returns on the same selected expiry, using only prior-session open interest for selection. Current-day open interest cannot select the return contract. The selected contract must be present and traded on both endpoints; missing or nontraded endpoints mask the return, without replacing the contract or filling a zero. There is no continuous `I0` series, back-adjustment, synthetic price index or roll-level jump.

The [SHFE 2014 rules](https://www.shfe.com.cn/upload/20141210/1418200411012.pdf), Article 49, define a traded contract's daily settlement as its volume-weighted trade price. The [SHFE PFMI disclosure](https://www.shfe.com.cn/eng/services/PFMI/PFMI/202412/W020250529522472510466.pdf) documents the 15:00 day-session close. Some older daily files carry a 2015 migration timestamp; that is retained as archive metadata and is not a multi-year information lag. Revision frequency cannot be identified from a single preserved vintage and is reported as unknown.

The [official SHFE excluded-date calendar](https://www.shfe.com.cn/data/config/js/trade-data.js) covers 2015–2024. Its meaning is verified by the [exchange daily-data UI](https://www.shfe.com.cn/images/report_data_dailyAndweekly.js), which takes its complement to identify trading dates. Missing weekdays outside the verified closed-date set mask gap-spanning returns; an HTTP 404 is never itself proof of a holiday. Pre-2015 weekday gaps remain explicitly unresolved. The same mainland schedule conservatively detects missing DCE sessions; a possible extra DCE closure masks a move rather than overstating its horizon.

**DCE limitations and held-out boundary.** All 60 expired-contract requests I1401 through I1812 returned explicit null responses. Direct official dated `dayQuotes` API probes for 2013-10-18, 2018-01-02 and 2024-12-30 timed out over HTTPS; the HTTP probe returned 412. These failures are not proof that no exchange archive exists. The available source is an unofficial mirror whose correction history is unknown. Existing I19–I24 expiry files are hash-verified; their earliest usable source date is 2018-05-07. Existing I25 expiry files contain legitimate 2024 observations. Their consumer reads an unbuffered chronological prefix and stops after the first excluded date marker, before any excluded price, volume or open-interest payload. Full-file hashes for those future-expiry files are inherited from the sealed manifest, not recomputed by reading held-out bytes. No new 2025 expiry request or annual 2025/2026 historical download is made.

**US prices, identity and calendar.** EWZ and 17 ADR symbols each have 3,773 vendor rows from 2010-01-04 to 2024-12-30; BBDO has 3,221 from 2012-03-13. The 18-symbol list is a requested archive extension, not a claim to reconstruct every historical Brazilian ADR or a survivor-free historical ADR universe. Ticker history must be joined to dated B3 identity before any per-name feature is admitted.

Yahoo OHLC is historically split adjusted; adjusted close also reflects distributions ([vendor definition](https://help.yahoo.com/kb/SLN28256.html)). Neither is proven to be the contemporaneous cash price required for an ADR premium. Future common multiplicative adjustments cancel in log returns, but rounding and correction revisions remain unidentifiable. All premium fields are null. US return endpoints must be adjacent observed EWZ sessions with positive observed prices and volumes; a missing stock session cannot turn a multi-session move into a one-session return.

US bars are dated at their session but become available at the actual 16:00 New York close, or 13:00 on a scheduled early close. IANA zones handle historical New York and Brazilian DST. An early close can reach the same B3 15:45 decision; a blanket one-day lag would lose valid information. Archived primary schedules include [NYSE 2014–2015](https://ir.theice.com/press/news-details/2013/NYSE-Euronext-Announces-2015-Holiday-Calendar-and-Early-Closings/default.aspx), [2016–2017](https://ir.theice.com/press/news-details/2016/NYSE-Group-Announces-2017-Holiday-and-Early-Closings-Calendar/default.aspx), [2018–2020](https://ir.theice.com/press/news-details/2017/NYSE-Group-Announces-2018-2019-and-2020-Holiday-and-Early-Closings-Calendar/default.aspx), [2021–2023](https://ir.theice.com/press/news-details/2020/NYSE-Group-Announces-2021-2022-and-2023-Holiday-and-Early-Closings-Calendar/default.aspx), and [2022–2024](https://ir.theice.com/press/news-details/2021/NYSE-Group-Announces-2022-2023-and-2024-Holiday-and-Early-Closings-Calendar/default.aspx), with earlier Nasdaq/BATS notices in the documentation manifest.

Suzano is an explicit exception: its issuer [announced NYSE trading from 2018-12-10](https://www.prnewswire.com/news-releases/suzano-papel-e-celulose-sa-announces-the-listing-of-its-american-depositary-receipts-adrs-300760263.html), after an OTC segment under SUZBY. Earlier Yahoo SUZ history is preserved but has no verified availability timestamp and is excluded from timed consumers. Current ticker metadata is not used to backdate an exchange listing or historical B3 identity.

**Validation.** Nineteen focused tests protect nominal DI maturity selection, partial-curve retention, requested-date bounds, unbuffered held-out-prefix exclusion, prior-open-interest contract selection, exact-contract return continuity, missing-session masks, early-close/DST timing, first eligible decision under source mutation, vendor metadata isolation, and raw-byte immutability. The normalized archive is pending the parent task's joined-consumer acceptance proof; raw coverage alone is not a claim that every feature is admitted.
