# Brazil-RV current multi-day refactor acceptance checklist

This checklist maps the engineering work order in
`Brazil_RV_Multiday_Refactor_Plan.md` to repository evidence. It deliberately
separates three different claims:

- **Pass — implementation/fixture:** the current semantic contract is
  implemented and protected by deterministic tests.
- **Unsupported — real source:** the interface and conservative failure mode
  exist, but the repository does not contain the authoritative historical
  evidence needed to accept that capability on real data.
- **Not run / not authorized:** registered development research was outside
  this refactor and was not started.

The lifecycle status of a command is not an engineering-acceptance result. A
builder, trainer, or report command may complete while engineering acceptance
remains `unsupported`. No current-schema real-data rebuild, research score,
official-validation read, permanently spent test read, or deployment change
is claimed here.
